# ai-term-radar-mini
A tiny Python radar that surfaces emerging AI terms from recent Hacker News stories.

## RS485 编码器板链监控

独立的 `encoder_dashboard.py` 用于布瑞特 131072P-17 多圈 RS485 编码器，与上述雷达程序互不影响。需要 Python 3.10+、USB 转 RS485 适配器及图形桌面环境：

```bash
python -m pip install -r requirements-encoder.txt
python encoder_dashboard.py
```

V0.4 启动时显示默认看板，仅显示端口、合理速度上限、保存目录及必要的连接操作，以及实时速度仪表、累计行程、最大／最小速度和速度／加速度趋势。“解锁专业看板”输入 `ENGNB` 可查看完整设置和数据；返回默认看板后再次进入需要重新输入。此密码仅用于界面切换，并非安全访问控制，不能保护本地 CSV、源码或程序中的数据。

连接 USB 转 RS485 适配器后，程序启动及点击“刷新端口”时会搜索 Silicon Labs CP210x（描述包含 CP210x，或 USB VID/PID 为 10C4:EA60）。仅找到一个且没有已选端口时自动预选；多个匹配时需手动选择，始终需要点击“确认 COM 口”，再点击“选择保存目录…”。确认编码器站号及波特率后点击“连接并开始采集”。默认站号 1、115200 波特率、8N1、50 ms 轮询；波特率、站号和轮询周期在专业看板设置，返回默认看板不会重置其值。波特率应与设备当前配置一致，程序不会自动修改设备。轮询周期仅为请求间隔，实际采样率取决于串口及设备响应。

真实采集时会显示“真实编码器”；专业看板的“模拟输入设置…”打开二级窗口，只有点击“开始模拟”才启动不使用串口的模拟，界面和 CSV 均明确标记模拟。真实采集和模拟均需由用户选择 CSV 保存目录；停止或关闭窗口时会关闭文件。

通信超时、短帧、错误帧或 CRC 错误会提示并重试；连续 5 次失败才停止采集，成功响应会重置失败次数。串口打开／读写硬件错误、设备返回的 Modbus 异常、文件错误和超出合理速度上限仍立即停止。通信异常期间读数失效；恢复后 CSV 的 `communication_gap` 标记为 1，恢复点不计算速度和加速度，5 秒平均窗口重新预热。间隔内的运动无法还原，净位移按中断前后位置差估算，累计行程可能低估（例如期间反向），并会持续显示警告；真实设备回绕仍无法推断。重试不能替代检查供电、接线、终端匹配和 USB/RS485 转换器。

**Windows 打包与实机验证**

在 Windows 上安装 Python 3.12，打开 PowerShell，在项目目录执行 `.\build_encoder_windows.ps1`。脚本将生成 `dist\EncoderMonitor_V0.4.exe`；Windows 可执行文件必须使用 Windows 环境构建。启动 EXE 后：

1. 检查编码器供电、RS485 A/B 和 USB 适配器，记下 Windows 设备管理器中的 COM 号；选择并确认该端口。
2. 选择 115200、站号 1（或设备实际站号），停止机械后连接。确认状态显示真实编码器而不是模拟，静止时速度接近零。
3. 低速正转、反转，核对方向和位移；按 200 mm/圈检查一圈读数。用已知距离和参考计时比较 5 秒平均速度，检查加减速曲线和 CSV。
4. 确认编码器计数的物理量程和量程边界行为；避免跨越边界后误读，先按实际设备设置合理速度上限。禁止依赖软件作为安全联锁。

**测量定义**

- 使用 `03` 功能码读取 `0x0000～0x0001` 的多圈位置，每圈 131072 计数，计米轮有效周长固定为 0.200 m，并假设编码器与轮轴 1:1 转动。
- 实时速度为相邻位置之差除以实际单调时钟间隔；平滑速度为时间常数 0.25 秒的因果指数平滑，不是对未来数据进行曲线拟合。实时加速度为相邻区间速度之差除以其中心时刻间隔；平滑加速度为平滑速度的变化率。
- 图表 05 可切换实时速度或 5 秒平均速度，横轴可设置 1～60 分钟。5 秒平均值为最近 5 秒的带方向净位移除以 5 秒，窗口边界线性插值；不足完整 5 秒时曲线无数据、CSV 留空。
- 最大和最小速度按每次有效实时速度采样更新，保留方向并显示发生于本次采集开始后的秒数；CSV 每行记录截至该采样的极值及对应时间。每次启动重新统计，速度相同时保留首次发生时间。波动范围是最近最多 5 秒的实时速度最小值至最大值；启动不足 5 秒时使用已有采样。
- 净位移可为负，累计行程是各采样间位移绝对值之和。正方向由编码器设置和安装方向决定。图表数据按时间保留最近 60 分钟，CSV 保存完整采集记录。
- 图表 03 和 04 分别显示最近 60 秒的速度及加速度趋势，横轴使用相同的秒数范围；图表 05 独立以分钟显示。速度图纵轴固定为所设速度上限的 ±1.2 倍，加速度纵轴按数据自动缩放，颜色图例区分数据线。距离仅在数字卡片与 CSV 中显示。

**使用注意**

- 机械可持续旋转并不意味着多圈位置寄存器无限：该编码器有物理量程，连续运行仍可能跨越计数边界。界面不再设置硬件圈数，也**不会自动展开真实编码器的计数回绕**；应向厂家确认量程和边界行为，跨越边界可能产生错误读数或中断采集，不能保证无间断长期测量。模拟数据使用独立的已知模拟量程。
- “合理速度上限”默认 5 m/s，仅用于检测异常跳变，须按设备实际情况调整；超过上限时会停止采集。它不能识别所有回绕或复位，也不是安全保护。
- 计米轮必须与板链稳定接触；打滑、有效周长、传动比、时间抖动和滤波都会影响准确性与响应。应使用已知距离和参考速度进行现场校准，不要用于安全联锁。
- 本程序只读取位置，不修改设备零点、波特率或采样设置。说明书接线为红色电源正、黑色 0V、白色 RS485 A、绿色 RS485 B，黄色功能线正常运行时悬空并绝缘；接线前应核对具体设备铭牌和适配器标识。

运行计算和协议测试：`python -m unittest discover -s tests`。

### 浏览器模拟面板

`web/` 是无需安装依赖的静态网页，在浏览器中模拟 17 位多圈编码器位置输入；其平均窗口仍为 3 秒，与桌面程序的 5 秒选项不同。通过滑块可以调整目标速度（含反向）和加速度限制，支持暂停、重置和下载 CSV（最多保留本次最近 72,000 个采样点）。页面不连接真实串口，数据不会上传，也不代表实际设备状态。

本地预览：

```bash
python -m http.server 8000 --directory web
```

在浏览器打开 `http://localhost:8000/`。也可将 `web/` 的内容部署到静态网页服务。模拟硬件圈数仅用于演示，不代表实际设备圈数；浏览器后台限速会影响采样间隔。3 秒平均值需完整窗口，净位移和平均速度带方向。

若使用 GitHub Pages，在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支设为 `gh-pages`，目录设为 `/ (root)` 并保存。此演示为公开网页，每位访问者的数据仅在自己的浏览器中生成和保存；这不是实时采集真实设备的云服务。

网页模拟器计算与 Python 版本的一致性可用 `node --test tests/test_web_simulation.mjs` 检查（需要 Node.js）。
