# ai-term-radar-mini
A tiny Python radar that surfaces emerging AI terms from recent Hacker News stories.

## RS485 编码器板链监控

独立的 `encoder_dashboard.py` 用于布瑞特 131072P-17 多圈 RS485 编码器，与上述雷达程序互不影响。需要 Python 3.10+、USB 转 RS485 适配器及图形桌面环境：

```bash
python -m pip install -r requirements-encoder.txt
python encoder_dashboard.py
```

连接 USB 转 RS485 适配器后，点击“刷新端口”，从下拉列表选择对应 COM 口并点击“确认 COM 口”，确认编码器站号及波特率后点击“连接并开始采集”。默认站号 1、115200 波特率、8N1、50 ms 轮询；波特率应与设备当前配置一致，程序不会自动修改设备。轮询周期仅为请求间隔，实际采样率取决于串口及设备响应。

真实采集时会显示“真实编码器”；“模拟输入设置…”打开二级窗口，只有点击“开始模拟”才启动不使用串口的模拟，界面和 CSV 均明确标记模拟。点击“选择编码器照片…”可从本机加载照片，程序仅记住文件路径，不上传照片。原始 Python 程序将 CSV 保存到启动目录；打包后的 EXE 保存到用户的 `Documents\EncoderMonitor`。停止或关闭窗口时会关闭文件；通信或文件错误会中断采集并显示原因。

**Windows 打包与实机验证**

在 Windows 上安装 Python 3.12，打开 PowerShell，在项目目录执行 `.\build_encoder_windows.ps1`。脚本将生成 `dist\EncoderMonitor.exe`；Windows 可执行文件必须使用 Windows 环境构建。启动 EXE 后：

1. 检查编码器供电、RS485 A/B 和 USB 适配器，记下 Windows 设备管理器中的 COM 号；选择并确认该端口。
2. 选择 115200、站号 1（或设备实际站号），停止机械后连接。确认状态显示真实编码器而不是模拟，静止时速度接近零。
3. 低速正转、反转，核对方向和位移；按 200 mm/圈检查一圈读数。用已知距离和参考计时比较 3 秒平均速度，检查加减速曲线和 CSV。
4. 确认厂家的硬件总圈数后再设置回绕；若未知则保留“未知”，避免跨越量程。先按实际设备设置合理速度上限，禁止依赖软件作为安全联锁。

**测量定义**

- 使用 `03` 功能码读取 `0x0000～0x0001` 的多圈位置，每圈 131072 计数，计米轮有效周长固定为 0.200 m，并假设编码器与轮轴 1:1 转动。
- 实时速度为相邻位置之差除以实际单调时钟间隔；平滑速度为时间常数 0.25 秒的因果指数平滑，不是对未来数据进行曲线拟合。实时加速度为相邻区间速度之差除以其中心时刻间隔；平滑加速度为平滑速度的变化率。
- 3 秒平均速度是最近 3 秒的带方向净位移除以 3 秒，窗口边界线性插值。3 秒平均加速度是平滑速度在该窗口内的变化除以 3 秒。窗口数据不足时显示“等待数据”，CSV 对应字段留空。
- 净位移可为负，累计行程是各采样间位移绝对值之和。正方向由编码器设置和安装方向决定。曲线保留最近 1200 个采样点，CSV 保存完整采集记录。

**使用注意**

- “硬件总圈数”必须填写厂家确认的编码器硬件圈数，而不是实时转过的圈数；未知时保持 0，程序不会假设量程或自动处理回绕。圈数已确认时，程序按 `圈数 × 131072` 展开位置，并在采样间隔不足以区分回绕时停止。最大支持总计数为 2³²；说明书中更大圈数与 32 位位置寄存器的关系应向厂家确认。
- “合理速度上限”默认 5 m/s，仅用于检测异常跳变，须按设备实际情况调整；超过上限时会停止采集。它不能识别所有回绕或复位，也不是安全保护。未知硬件圈数时尤其要避免跨越量程边界，否则可能出现无法识别的错误值。
- 计米轮必须与板链稳定接触；打滑、有效周长、传动比、时间抖动和滤波都会影响准确性与响应。应使用已知距离和参考速度进行现场校准，不要用于安全联锁。
- 本程序只读取位置，不修改设备零点、波特率或采样设置。说明书接线为红色电源正、黑色 0V、白色 RS485 A、绿色 RS485 B，黄色功能线正常运行时悬空并绝缘；接线前应核对具体设备铭牌和适配器标识。

运行计算和协议测试：`python -m unittest discover -s tests`。

### 浏览器模拟面板

`web/` 是无需安装依赖的静态网页，在浏览器中模拟 17 位多圈编码器位置输入，并使用与桌面程序相同的测量定义。通过滑块可以调整目标速度（含反向）和加速度限制，支持暂停、重置和下载 CSV（最多保留本次最近 72,000 个采样点）。页面不连接真实串口，数据不会上传，也不代表实际设备状态。

本地预览：

```bash
python -m http.server 8000 --directory web
```

在浏览器打开 `http://localhost:8000/`。也可将 `web/` 的内容部署到静态网页服务。模拟硬件圈数仅用于演示，不代表实际设备圈数；浏览器后台限速会影响采样间隔。3 秒平均值需完整窗口，净位移和平均速度带方向。

若使用 GitHub Pages，在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支设为 `gh-pages`，目录设为 `/ (root)` 并保存。此演示为公开网页，每位访问者的数据仅在自己的浏览器中生成和保存；这不是实时采集真实设备的云服务。

网页模拟器计算与 Python 版本的一致性可用 `node --test tests/test_web_simulation.mjs` 检查（需要 Node.js）。
